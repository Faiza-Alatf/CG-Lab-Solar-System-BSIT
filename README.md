# Interactive Solar System Simulation (OpenGL + GLUT)
This project is a 3D interactive solar system simulation developed using C++ and OpenGL/GLUT for the Computer Graphics Lab.

## Features
- Sun as central light source  
- Planetary revolution and rotation  
- Moon orbiting planets (hierarchical modeling)  
- Texture mapping (Earth, Mars, etc.)  
- Lighting (ambient, diffuse, specular)  
- Camera controls (zoom, rotate, flyby)  
- Keyboard & mouse interaction  
- Smooth animation (double buffering)  

##  Tech Stack
- C++
- OpenGL
- GLUT

##  Controls
- Arrow keys → rotate camera  
- Mouse → view control  
- + / - → speed control  
- Space → pause/resume animation  

## Project Structure
- src/ → main code
- assets/ → textures
- include/ → headers
- docs/ → reports & proposal
