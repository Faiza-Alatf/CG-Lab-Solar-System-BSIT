## Description
Interactive 3D Solar System Simulation using C++, OpenGL and FreeGLUT.

## Features
- 8 Planets with procedural textures
- Animated Drone/Spacecraft
- Asteroid Belt and Kuiper Belt
- Comet with tail effect
- Shooting Stars
- Planet Info Panel (Press 1-8)
- Drone Camera Mode [D]
- Top-Down View [T]
- Fullscreen [F]

## Project Structure
include/camera.h
src/main.cpp
src/camera.cpp
src/input.cpp

## Controls
[P] Pause    [+/-] Speed    [R] Reset
[1-8] Planet Info           [0] Close
[D] Drone Cam  [T] Top View [ESC] Quit
